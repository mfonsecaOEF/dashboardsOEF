# dashboardsOEF

Public Streamlit dashboards for Open Earth Foundation.

## Data coverage

City-scale public-data availability for **mitigation (GPC)** and **adaptation (CCRA)** across 9 countries.

- Package: [`data_coverage/`](./data_coverage/)
- Metrics spec + computed outputs: `data_coverage/coverage_metrics_spec.md`, `data_coverage/comparison_unified/`
- Local app: `data_coverage/streamlit_app/`
- **Streamlit Community Cloud main file:** `data_coverage/streamlit_app/app.py`
